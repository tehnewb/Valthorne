# Valthorne 2.4.0

Valthorne 2.4.0 expands the texture and NanoVG widget sets and reorganizes the
graphics, geometry, and audio APIs. This release requires Java 25.

## Changes

- Add and refine file browsers and choosers, menus, color and numeric controls,
  breadcrumbs, directory trees, collapsible sections, and resizable windows.
- Expand the NanoVG widget family and refine UI behavior and styling.
- Split model assets, scene objects, and rendering infrastructure into focused
  packages; place 3D point lights with the lighting subsystem.
- Move shared position and size contracts into the geometry package.
- Share filesystem navigation, filtering, ordering, selection, activation, and
  callbacks between the texture and NanoVG file explorers.
- Flatten the audio API into `valthorne.audio`.
- Remove the previous automated test suites, compatibility applications, test
  runners, and associated CI jobs. Retain compilation, documentation, and
  publication-artifact validation.

## Migration

These package changes break source and binary compatibility. Update imports and
recompile applications:

| Previous location | New location |
| --- | --- |
| `graphics.model` scene types and instances | `valthorne.graphics.scene` |
| `graphics.model` batches, renderers, shadows, and culling | `valthorne.graphics.render` |
| `graphics.model.PointLight3D` | `valthorne.graphics.lighting3d.PointLight3D` |
| `ui.Sizeable`, `ui.Locatable`, `ui.Dimensional` | `valthorne.math.geometry` |
| `valthorne.audio.sound` | `valthorne.audio` |
| `FileExplorer.Entry`, `NanoFileExplorer.Entry` | `valthorne.ui.behavior.DirectoryBrowserModel.Entry` |

Model geometry, materials, builders, parameters, and loaders remain in
`valthorne.graphics.model`. See the [package migration guide](../package-layout.md)
for additional details.

## Dependency

```groovy
implementation 'io.github.tehnewb:Valthorne:2.4.0'
```

## Validation and limitations

Release validation covers the desktop library, source and Javadoc archives,
documentation links, runtime resources, publication metadata, and signing.
The companion examples compile against the reorganized APIs, and temporary
headless checks exercised the shared directory-browser model. The removed test
suites no longer provide runtime regression coverage.

The development browser target still has compilation failures in its Java 17
compatibility and native API adaptations. This release does not claim a working
browser export. Browser exports also now require an explicit application entry
point because the bundled test launcher was removed.
