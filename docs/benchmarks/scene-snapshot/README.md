# Scene snapshot collection

This directory preserves the 2026-09-10 scene-collection measurements, source
snapshots, hashes, native checks, and framebuffer captures.

- [Accepted results](RESULTS.md): the controlled comparison, implementation,
  measured limits, and reproduction commands.
- [Preliminary investigation](PRELIMINARY.md): the original preparation notes and
  contaminated baseline. These observations are historical, not accepted
  before/after performance evidence.
- [Subsequent collection pooling](../scene-collection-pools/README.md): later
  material pooling, hierarchy traversal, retained-capacity analysis, and bounded
  flare-shadow work.

The raw reports and `before-sources/` and `after-sources/` directories identify
the implementations measured at the time. Preserve these records and their
source/class hashes. For current development commands, use the
[release checks](../../releasing.md) and [examples guide](../../examples.md).
